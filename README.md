# Кто пчёлок уважает

Браузерная текстовая RPG. Работает без сборки и без сервера: можно открыть `index.html` двойным кликом или выложить папку на GitHub Pages как есть.

## Структура

- `index.html` — каркас страницы, порядок подключения скриптов
- `css/style.css` — оформление
- `js/data.js` — навыки, герои, мысли
- `js/engine.js` — движок: реплики, проверки, мысли, чат, сохранения, панели
- `js/visual.js` — фон-шейдер, портреты, глаз, пчёлы
- `js/audio.js` — синтезированный звук
- `story/*.js` — сцены, по файлу на локацию

## Как устроена сцена

```js
Game.add({
  my_scene: {
    place: ['Подзаголовок', 'Заголовок'],   // необязательно
    pal: 'k1', npc: 'rusya',                // палитра и портрет, необязательно
    text: [                                  // массив или функция S => массив
      ['n', 'Текст рассказчика.'],
      ['rusya', 'Реплика героя.'],
      ['log', 'Голос навыка.'],
      ['enc>3', 'Пассивный голос: звучит, только если навык не ниже 3.'],
      ['chat:bogdan', 'сообщение в чате'],
      ['n', 'Строка с условием.', S => S.f.flag]
    ],
    opts: [
      {t: 'Простой ответ.', go: 'other_scene'},
      {t: 'Ответ один раз.', once: 1, say: [['n', 'Что произошло.']], fx() { R(1); XP(10) }},
      {t: 'Только при навыке.', need: ['sweet', 3], go: 'x'},
      {t: 'Проверка.', check: {sk: 'chit', dc: 10, red: 1, mods: [[S => S.f.x, 1, 'подпись бонуса']]},
        ok: {say: [], fx() {}, go: 'a'}, fail: {say: [], fx() {}, go: 'b'}}
    ]
  }
});
```

Без `go` ответ возвращает в ту же сцену. Белая проверка (без `red`) после провала запирается, пока навык не вырастет. Красная даётся один раз.

Эффекты: `R(n)` уважение, `ST()` укус, `CR(n)` кринж, `XP(n)` опыт, `TH('id')` новая мысль. Флаги: `S.f.что_угодно`.

Новый файл сцен нужно подключить в `index.html` перед `js/main.js`.

## Добавлено в третьей версии

- **Мини-игра вместо броска:** `game: {type: 'dance' | 'balance' | 'still' | 'rhyme' | 'chess', sk: 'wag', red: 1, mods: [...]}` плюс ветки `ok` и `fail`, как у проверки. Навык делает мини-игру легче.
- **Метка на картинке:** `pin: [x%, y%, 'Подпись']` у ответа — на сцене появляется кликабельная метка.
- **Время дня:** каждый ответ в локации тратит один шаг из `DAY` (в `js/engine.js`). Когда шаги кончаются, наступают сумерки и героя ведут к Матке. Ответ с `free: 1` и уход на развилку время не тратят.
- **Пороги финалов:** `TOP` и `MID` в первой строке `story/hive.js`.
- **Арты:** картинки из `assets/img/` подхватываются сами по именам из `assets/PROMPTS.md`. Фон сцены задаётся ключом `bg: 'kitchen'` (файл `bg_kitchen.jpg`).

## Арты и анимация (четвёртая версия)

- `assets/web/` — сжатые картинки, которые грузит игра. Их и нужно выкладывать на GitHub Pages.
- `assets/img/` — оригиналы из нейросети (по 3 МБ). Для сайта не нужны, можно не выкладывать.
- `js/artfx.js` — «живая картина»: фон течёт и дышит, реагирует на мышь, поверх летают пчёлы, идёт пар, дым, капает вода. Эмиттеры задаются в таблице `EMIT` в координатах картинки (0..1).
- Метка с координатами картинки: `pin: [x%, y%, 'Подпись', ix, iy]` — последние два числа привязывают метку к месту на арте.
- Живая картина работает на сайте. При открытии `index.html` двойным кликом браузер не даёт её включить, и фон показывается обычной картинкой.
